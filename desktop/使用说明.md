# 兔兔喝水 · 桌面版 v1.1.0

## 安装

适用于 macOS 13 及以上，下载包同时包含 Apple 芯片和 Intel 版本。目前实际运行验证环境为 Apple 芯片 Mac。

1. 解压 `TutuWater-v1.1.0-macOS-universal.zip`。
2. 将「兔兔喝水.app」拖入「应用程序」文件夹。
3. 双击启动，兔兔会出现在桌面右下角。
4. 单击兔兔展开页面，选择「开始陪伴」。

### 首次打开提示

当前版本采用本地签名，尚未经过 Apple Developer ID 签名和公证。首次从互联网下载后，系统可能提示无法验证开发者。

确认下载来源可信且文件未被改动后，可在尝试打开后进入「系统设置 → 隐私与安全性」，找到这款应用并选择「仍要打开」，然后在后续提示中确认。具体操作见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 日常使用

- **单击兔兔**：展开完整的喝水页面。
- **关闭窗口 / 收回桌面**：回到悬浮兔兔，提醒继续计时。
- **按住拖动**：调整兔兔的位置，下次启动会记住。
- **右键兔兔**：快速记录喝水、暂停 / 继续、延后提醒或退出。
- **菜单栏的小兔图标**：也能展开页面或退出。

默认 45 分钟提醒，可在设置中调整为 1–240 分钟。到点后兔兔会举杯、轻跳和摇摆，显示「该喝水啦！点我打开客户端并记录」。提示持续到你记录、延后或暂停。单击兔兔只打开页面，尚未记录就关闭页面时，兔兔会继续提醒。

无需开启系统通知也有兔兔动画；如需通知中心提示，可在设置中主动开启通知。系统开启「减少动态效果」时，保留举杯姿态和醒目的提示气泡。

## 更新与数据

更新前先右键旧兔兔，选择「退出兔兔喝水」，再用新版本替换应用。重新打开即可继续使用，记录与设置会保留。

记录和设置保存在这台 Mac 的 `~/Library/Application Support/TutuWater/water-state.json`，与网页版独立保存，不上传数据。关闭页面不会停止计时。退出应用或电脑休眠时不会提醒，重新启动或唤醒后会检查到期时间。

需要完全关闭时请选择「退出兔兔喝水」。桌面版不需要浏览器或联网，不会自动设置开机启动。

## 查看文件是否完整

发行版同时提供 `SHA256SUMS.txt`。需要核对下载文件时，可在下载目录的终端执行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

显示 `OK` 表示下载的压缩包与校验文件一致。校验文件应从同一个发行版下载。
